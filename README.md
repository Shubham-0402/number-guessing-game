# 🎮 Number Guessing Game (Python)

A simple and fun **Number Guessing Game** built using Python.  
The computer randomly selects a number between **1 and 100**, and the player tries to guess it in as few attempts as possible.

---

## 📌 How the Game Works

- The program generates a random number between **1 and 100**
- You enter guesses from the keyboard
- The game tells you whether your guess is:
  - 🔽 Too low  
  - 🔼 Too high  
- The game ends when you guess the correct number
- Your performance is judged based on the number of attempts

---

## 🧠 Scoring Logic

- **≤ 3 attempts** → 🧠 *Mind Reader!*  
- **More than 3 attempts** → 👏 *Very Good!*

---

## 🛠️ Technologies Used

- Python 3
- `random` module
