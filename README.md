# 🎯 Number Guessing Game

A simple **Number Guessing Game built with Python** as a beginner project to practice fundamental programming concepts.

The program generates a number and challenges the player to guess it, providing feedback based on each attempt.

## 🐍 About the Project

This project was created as a small Python practice project while learning the fundamentals of programming.

It focuses on understanding how basic Python concepts can be combined to create a simple interactive program.

## ✨ Features

* 🎲 Random number generation
* ⌨️ User input
* 🔍 Guess comparison
* 💡 Feedback for incorrect guesses
* 🏆 Simple interactive gameplay

## 🛠️ Technologies

* **Python**
* Python standard library

## 📚 Concepts Practiced

Building this project helped me practice:

* Variables
* User input
* `if / elif / else`
* Loops
* Conditional logic
* Random number generation
* Basic program flow

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Shubham-0402/number-guessing-game.git
```

### 2. Open the project

```bash
cd number-guessing-game
```

### 3. Run the program

```bash
python main.py
```

> If the Python file has a different name in the repository, use that filename instead.
